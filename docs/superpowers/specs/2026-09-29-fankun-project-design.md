# “饭困”项目作品集更新设计

## 目标

将“饭困”AI 饮食决策助手作为新的第一项作品加入个人作品集。第一阶段完成素材接入与顺序展示；第二阶段在静态长图前加入来自 Figma Section 2 的核心可操作原型。

## 首页作品卡片

- 项目 ID：`fankun`
- 排列位置：第 1 位
- 标题：饭困
- 副标题：AI 饮食决策助手
- 类别：产品设计 / UI UX
- 年份：2026
- 封面：源文件 `1 · 封面（分层可编辑）.png`
- 现有四个项目依次顺延为 02–05
- 卡片沿用现有作品列表组件、交互和视觉规则

## 详情页

- 为 `fankun` 增加独立详情页路由
- 详情页采用“连续长卷”方案
- 19 张图片严格按源文件编号 1–19 排列
- 每张图片按原始宽高比显示，不裁切、不变形、不改字
- 每张图片沿用网站现有的柔和圆角，与首页项目卡片和详情页视觉语言保持一致
- 图片之间仅保留必要的网页节奏间距，不添加章节标题或重新编组
- 页面保留现有站点导航和返回作品集入口

## 素材与加载

- 原始 PNG 复制到独立的项目素材目录，保留为源文件
- 为网页展示生成同尺寸或等比例的 WebP 副本，避免直接加载全部高体积 PNG
- 首图使用高优先级加载，后续图片使用懒加载和异步解码
- 图片替代文本按“饭困项目作品集第 N 页”命名，保证顺序和可访问性明确

## 交互原型（第二阶段）

- 原型嵌入详情页头部与静态长图之间，采用 393 × 852 手机画板呈现
- 视觉遵循 Figma Section 2：饭困青柠 `#C6DF46`、矿物白 `#F4F6F1`、暖炭黑 `#1B1F19`、14px 圆角与轻投影
- 核心流程：首页需求示例 → 外卖/到店对话 → 编辑条件 → 分类决策 → 推荐结果 → 菜品详情
- 推荐页支持换一批、进入详情、保存决定；详情页支持份量切换、加入购物车与结算反馈
- 底部导航的首页、决策、购物车、我的均有可见响应，不设置无反馈的按钮
- 使用 React 本地状态与模拟数据，不调用真实登录、支付、定位或第三方外卖接口
- 吉祥物、菜品和环境图片来自 Figma 原始素材，并保存到项目本地目录
- 原型界面置于作品集深色展示舞台中，保留网页整体的圆角与编辑感版式

## 实现边界

本轮不包含：

- 重做 PNG 内的文字、图表或手机界面
- 逐一实现 Section 2 的全部 53 个画板
- 真实账号登录、支付、下单、定位、多人在线饭局或服务端推荐
- 增加视频或复杂时间轴动效
- 修改全站导航、首页主视觉或其他项目详情页

## 异常处理

- 若个别源文件无法转换，则保留 PNG 作为该页的展示资源
- 构建前核对 19 个资源路径，避免详情页出现缺图
- 长图保持自然高度，不通过固定高度或 `object-fit: cover` 截断内容

## 验收标准

1. 首页第一张作品卡片为“饭困”，其余项目编号正确顺延。
2. 点击卡片可进入“饭困”详情页，返回链接可正常回到首页。
3. 详情页完整显示 19 张图片，顺序为 1–19。
4. 所有图片保持原始比例，无裁切、拉伸和错序。
5. 首图可优先显示，后续图片可随滚动加载。
6. 生产构建通过，浏览器控制台无素材路径错误。
7. 外卖与到店入口均可进入条件对话，条件可编辑并保存。
8. 分类选择、推荐换批、菜品详情、份量选择、加入购物车与结算反馈均可操作。
