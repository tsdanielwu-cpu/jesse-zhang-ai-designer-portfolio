# Portfolio Heading Spacing

## Scope

Adjust only the homepage portfolio section heading and the spacing before the first project.

## Approved Design

- Remove sticky positioning from the `PORTFOLIO` heading block.
- Keep the existing heading size and two-column heading composition.
- Place the heading in normal document flow so it remains fully visible.
- Increase the space between the heading and the first project to approximately 100px.
- Preserve the current project card dimensions and vertical project layout.
- Do not change the project animation, card content, or navigation.

## Verification

- The first LoRA project must not cover the `PORTFOLIO` title at the top of the section.
- The section heading must remain readable at the existing desktop viewport.
- The production build must complete successfully.
